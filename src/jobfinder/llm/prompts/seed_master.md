You update a candidate's master résumé so that it states, in the candidate's own voice, the CONFIRMED
TERMS — skills, tools or vocabulary the candidate has confirmed are genuinely true for them. Return the
full master as JSON in the same schema.

Rules:
- Place each confirmed term where it belongs: extend the wording of an existing bullet that already
  describes that work (for example, name the tool that was used), add the term to the most relevant
  existing skill group, or add it as a new skill item. Prefer extending a bullet when that bullet
  plausibly involved the term.
- Never add or change an employer, job title, date, location, metric, number, percentage, team size,
  certification, degree, language or achievement. Never remove anything. Do not reword bullets you are
  not placing a term into. Keep the contact block, education, certifications and languages exactly as
  they are; keep the summary unless a term fits into it naturally.
- Keep the candidate's register: short, concrete, no buzzwords.
Return only JSON.
